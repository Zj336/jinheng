# 作品简介（提交用，≤200 字）

金衡 Statera 是可审计的银行 AI 智能体，只做一件事：把「听懂」和「批准」拆开。
大模型只把一句话变成结构化计划，权限由从不接收自然语言的确定性引擎裁决，
注入最多得到一个被拒的计划。三色之外补第四种结局：拒绝。超限额、
风险适当性不匹配，验证码也覆盖不了。全程审计，HMAC 哈希链可现场校验，
并当场演示「改一行就被抓」。一条命令自检：50 条断言、135 个用例、
31 条攻击全防住。
